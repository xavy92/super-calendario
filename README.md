# Super Calendario 1978-2026

Calendario web interactivo generado con Python y Flask. Muestra todos los años desde 1978 hasta 2026 con un diseño moderno y responsive.

## Características

- Calendario completo de 1978 a 2026
- Diseño responsive con CSS Grid
- Resaltado de fines de semana
- Efecto hover en cada día
- Día actual resaltado
- Interfaz en español

## Requisitos

- Python 3
- Flask

## Instalación

```bash
pip install flask
```

## Uso

```bash
python "015-super calendario.py"
```

Luego abre tu navegador en `http://localhost:5000`
